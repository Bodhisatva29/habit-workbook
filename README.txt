Habit Workbook - installable web app (PWA)

1. Upload this whole folder to any free static host with HTTPS:
   Netlify Drop (app.netlify.com/drop), Cloudflare Pages, GitHub Pages or Vercel.
2. Share the resulting https link with anyone.
3. On Android, open the link in Chrome, then tap the menu (three dots) > "Install app" (or "Add to Home screen").
   It opens full screen and works offline.

Data is stored on each person's own device (browser storage), not on a server.
